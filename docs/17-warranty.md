## 1. Warranty Period & Terms

The developer provides a **30-day complimentary software warranty** starting on the official delivery date (**July 19, 2026**).

### 1.1 Covered Items
- Resolution of reproducible software defects or code errors.

- Restoration of database seed scripts if damaged during initial deployment.

### 1.2 Non-Covered Items & Exclusions
- Outages or failures caused by third-party infrastructure (Vercel, Neon, Supabase, Cloudinary).
- Requests for new features, new payment gateways, or additional pages.
- Loss of client credentials or unauthorized modifications made to the source code by third parties.
