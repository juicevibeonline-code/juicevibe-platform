## 🔍 Step 3: Google Search Console & Instant Indexing

To get your website indexed in Google Search within 24–72 hours:

1. **Add Property**:
   - Go to **[search.google.com/search-console](https://search.google.com/search-console)**.
   - Add Domain Property `https://juicevibe.lk`.
2. **Submit Sitemap**:
   - Navigate to **Sitemaps** in the left menu.
   - Submit sitemap URL: `https://juicevibe.lk/sitemap.xml`.
   *(The Next.js storefront dynamically generates this file at `/sitemap.xml`)*.
3. **Request Manual Indexing**:
   - Use **URL Inspection** tool to inspect `https://juicevibe.lk` and `https://juicevibe.lk/menu`.
   - Click **"Request Indexing"**.
