## ⚙️ 3. Platform Configuration Steps

### 1. Storefront App (`apps/web` on Vercel)
- Go to **Vercel Dashboard** ➔ Project `juicevibe-web` ➔ **Settings** ➔ **Domains**.
- Add `juicevibe.lk` and `www.juicevibe.lk`.
- Ensure environment variable is set:
  ```env
  NEXT_PUBLIC_API_URL=https://api.juicevibe.lk
  ```

### 2. Admin Dashboard (`apps/admin` on Vercel)
- Go to **Vercel Dashboard** ➔ Project `juicevibe-admin` ➔ **Settings** ➔ **Domains**.
- Add `admin.juicevibe.lk`.
- Ensure environment variable is set:
  ```env
  NEXT_PUBLIC_API_URL=https://api.juicevibe.lk
  ```

### 3. Backend API (`apps/api` on Railway)
- Go to **Railway Dashboard** ➔ Service `juicevibe-api` ➔ **Settings** ➔ **Networking** ➔ **Custom Domain**.
- Add `api.juicevibe.lk`.
- Ensure CORS and service environment variables match:
  ```env
  FRONTEND_URL=https://juicevibe.lk
  ADMIN_URL=https://admin.juicevibe.lk
  ```
